# Coordinatez Axis

An immersive product experience for the Coordinatez Axis motorized pergola.

## Live demo

[Open the interactive 3D studio](https://parth-oza.github.io/coordinatez-axis-demo/)

## Experience

- Real-time canvas-rendered 3D pergola
- Drag-to-orbit camera controls
- Animated motorized louvers
- Live finishes, sizes, accessories, and pricing
- Landscape and evening-light modes
- Responsive desktop and mobile presentation
- Original Coordinatez visual identity and social preview artwork

## Development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Build the standalone GitHub Pages edition:

```bash
npm run build:pages
```

The deployable static output is generated in `docs/`.
